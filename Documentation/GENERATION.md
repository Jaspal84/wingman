# Deterministic MIDI generation

Select Chord, Bass, Drum or Melody MIDI in the right sidebar, then Generate selected part. Bass/drum/melody open a scrollable parameter editor. The engine is deterministic and local, not a trained generative model. All parts can be auditioned, selected for MIDI export, or dragged as a temporary standard MIDI file to a compatible DAW. Actual external DAW drag/drop and AU MIDI routing have not been tested on Linux; file export and processor MIDI are tested.

Parameters: seed, explicit global variation, 4/8/16/32 bars, eight style starting points, bass octave, velocity, melody pitch bounds, major/natural-minor scale, density, swing, humanization, length, complexity, root emphasis, syncopation, kick density, snare variation, fills, repetition, ghost notes, hat subdivisions and nine editable GM drum mappings. The panel shows common parameters; instrument-specific fields affect only their relevant engine. Not every knob affects every part.

Bass uses scale/chord intersections with strong-beat root emphasis and nearest-note voice-leading cost. Melody uses chord tones on strong beats and scale-constrained passing tones with bounded register and distance costs. Rhythm accents differ by style. Some high-complexity/range combinations can still produce large jumps; this is a rule-based composition starting point, not a claim of professional musical quality. Incompatible harmony/scale/range is rejected rather than silently emitting out-of-scale notes.

Drums use GM channel 10: kick 36, snare 38, clap 39, closed hat 42, open hat 46, percussion 75, toms 45/47/50, all editable. The Bhangra-inspired preset adds low/high tom call-response at distinct accented subdivisions; these are approximate MIDI starting rhythms, not authentic sampled dhol or a genre-quality benchmark. Other starting styles: Punjabi pop, Bollywood, hip-hop, trap, house, funk, acoustic pop. No artist imitation claim.

The compact MIDI view displays the selected part. For drums it becomes a nine-row, 16-step grid; the slider selects the bar and clicking a cell toggles its note. The parameter dialog can vary a chosen four-bar phrase while retaining all notes outside it. Global variation is explicitly separate and regenerates the full pattern. Editing harmony or transposition invalidates stale generated parts. Tempo changes change playback scheduling/export metadata without altering beat-domain note positions. Current generators use **4/4** only.

Click a bass or melody preview note to edit pitch, start, duration or velocity, or delete it. Timeline zoom/scroll also zooms the MIDI preview. A full drag-resize piano roll and selected-phrase melody candidate browser are not implemented. Drums are editable through the step grid. The internal audition is a basic synth, not a professional instrument library. No sample pack is bundled.

Version-1 state remains readable; optional `patterns` data stores parameter values and actual edited notes, rather than relying on regeneration to recreate a saved performance. Legacy plugins ignore the extra properties. Tests exercise all eight styles, all four lengths and all three kinds, seed reproducibility, scale/register/timing constraints, monophonic collisions, GM channel, variations, standard MIDI export and state round trips. Phrase-splice tests verify untouched bars are unchanged.
