# Sampled guitar validation — 2026-10-25

Environment: Linux x86_64, JUCE 8.0.6, GCC 14.2, Debug plugin build.

- VST3 and standalone targets: compiled and linked successfully.
- Full CTest suite: 14/14 passed in 22.42 seconds, including sampled_guitar and
  processor/editor integration. Sampled_guitar executes 20 direct checks.
- Existing portable suite: 12/12 passed in 24.00 seconds.
- SFZ tests: decoded stereo PCM24 fixture, deduplicated sample storage, numeric key
  mapping, two round-robin regions, velocity layers, sampled technique selection,
  release trigger, cancellation, unsupported opcode and missing-file errors.
- Render tests: stereo preservation, note-start timing and note-off decay at both
  44.1/48 kHz, missing attack coverage rejection.
- Processor tests: asynchronous verified library publication, sampled MIDI-to-WAV
  rendering, readable stereo PCM24 export at 48 kHz, engine/path state round trip
  with deferred manual verification after restoration. Existing tests retain 44.1
  kHz PCM24 export, MIDI note pairing and chord/guitar generation coverage.
- GUI integration: actual editor painting, controls inside panel bounds, engine
  controls alongside existing Preview/Render/Export/Drag controls.

All sampled test audio was generated by test code. These tests do not assess the
perceptual realism of recordings, full third-party SFZ compatibility, native macOS
file permissions, realtime allocation counts, or M1 CPU/RAM/thermal performance.
No model or sample recordings were downloaded for this change. Real Demucs inference
was not rerun: its worker and model are unchanged; existing worker/validation tests
passed as part of the full suite.

AU build/auval, Logic Pro and MainStage loading, native MIDI/WAV external dragging,
physical audio devices and M1 benchmarking remain manual. The user-provided prior
Wingman Pro 0.2.0 AU cold-open failure has not been resolved or retested here.

The current engine preloads libraries within a 256 MiB decoded budget. It does not
stream large tails or provide live incoming-MIDI sample voices. Preview plays an
asynchronously rendered lane. Mixed down/up sample articulation within a strumming
pattern, automatic fret-noise transitions, general SFZ keyswitch/controller support,
and a band-limited pitch resampler remain future work. Actual recorded guitar
articulations and instrument types require a suitable user-licensed library.
